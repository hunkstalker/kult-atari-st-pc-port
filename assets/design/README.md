# Fuentes de diseño

Esta carpeta contiene las fuentes editables de las imágenes de referencia del port:

- `Kult Settings.af`: fuente Affinity de `Kult Settings.png`.
- `Kult-Idiomas.af`: fuente Affinity de la pantalla de selección de idioma.

Los `.af` son los originales/editables y se conservan en el repositorio. Los PNG
exportados son los que se usan en la release (`assets/Kult Settings.png`) o como
referencia de la pantalla de idioma.

No se incluyen en el ZIP de release.

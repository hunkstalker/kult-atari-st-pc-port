# 0090 — T-096: corrección del workflow CI

Fecha: 2026-10-25. Estado: **corregido**; pendiente de force-push y primera
ejecución.

## Fallo observado

La primera ejecución de `make test-port` terminó bien, pero `make test-tools`
falló con:

`make: .venv/bin/python: No such file or directory`

El workflow no crea `.venv`; el Makefile heredado usa `.venv/bin/python` por
defecto para herramientas. Además, `pkg-config sdl3` se evaluaba al invocar
`make test-port` aunque ese target no necesita SDL3, generando avisos.

## Corrección

- `.github/workflows/release.yml`: `make test-tools PY=python`; el runner de
  GitHub instala `pytest` en el Python del sistema con `setup-python`.
- `Makefile`: `pkg-config --cflags/--libs sdl3 2>/dev/null` para no ensuciar
  `make test-port`. `port-sdl` sigue necesitando SDL3 y fallará de forma clara
  si no está instalado.

## Verificación

- `make test-port`: OK.
- `.venv/bin/python -m pytest -q test`: 5 passed.
- El ZIP no cambia.

## Pendiente

Force-push del commit de release y del tag `v1.0.0`; GitHub Actions generará el
ZIP de CI, su `.sha256` y la GitHub Release.

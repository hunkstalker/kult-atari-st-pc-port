# 0056 — T-103: savestate completo por ranura

Fecha: 2026-10-25. Estado: **cerrada**. Siguiente: T-104 (atajos).

## Formato

Cada ranura es un fichero `saves/slot-0.save` … `slot-9.save`:

```text
offset  tamaño  contenido
0       8       "KSLOTP01"
8       4       versión = 1 (u32 BE)
12      4       número de ranura (u32 BE)
16      32      paleta actual: 16 words ST (u16 BE)
48      4       base visible (u32 BE)
52      4       frame/VBL (u32 BE)
56      4       0x100000 (u32 BE)
60      4       reservado = 0
64      1 MiB   imagen plana completa del motor
```

La carga valida magia, versión, ranura, tamaño y longitud exacta **antes** de
tocar la imagen. Si el fichero falta, está truncado o no coincide, devuelve
error y deja la partida intacta. La escritura usa `.tmp` + reemplazo para no
dejar una ranura a medias.

T-107 renombró los ficheros de `partida-N.bin` a `slot-N.save`. Al arrancar se
migran automáticamente los antiguos si el nuevo no existe; la carga también
acepta el nombre antiguo y lo renombra.

## Persistencia

`kult.ini`, junto al ejecutable, guarda la ranura activa:

```ini
save_slot = 0
```

Al arrancar se lee; si falta o no es válida, se usa 0. El fichero se reescribe
preservando otras claves que pueda haber en el futuro.

## Integración

- `platform/slots.c`: formato, lectura/escritura, configuración y ciclo.
- `platform/video.c`: `platform_video_restore()` repone paleta y base visible.
- `platform/fs.c`: `platform_saves_dir()`.
- `platform/osd.c`: aviso `RANURA N`.
- `platform_init()` inicializa la ranura.

## Verificación

`make test-port` cubre:

- roundtrip de 1 MiB + paleta + base visible;
- tamaño exacto del fichero;
- ranura ausente y truncada sin tocar la imagen;
- slots fuera de rango;
- ciclo 0→3, persistencia en `kult.ini` y recarga de la ranura.

## Limitaciones

- El savestate no incluye el estado del MFP/PSG; la música no rebobina.
- El formato está pensado para la misma versión del port; la versión de
  cabecera permite rechazar formatos futuros desconocidos.

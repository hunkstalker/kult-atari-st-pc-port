# ADR 0001 — Usar SDL3

- **Estado:** aceptada
- **Fecha:** sesión 1

## Contexto
Necesitamos ventana, entrada, audio y acceso a GPU en **Windows y Linux** con la
misma base de código. Además queremos, más adelante, **shaders** para filtros CRT.

## Decisión
Usar **SDL3** (ventana, entrada, audio, GPU), con `SDL_Renderer` para lo básico y
`SDL_GPU` para los shaders.

## Consecuencias
- Una sola dependencia multiplataforma; SDL3 es la versión actual y Valve la
  mantiene activamente.
- Habilita filtros CRT sin bajar a Vulkan/D3D a mano.
- El core (juego) no depende de SDL: solo la capa `platform/`.
